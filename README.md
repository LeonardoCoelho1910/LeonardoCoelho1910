## Sobre mim

Gosto de transformar processos manuais em aplicações simples, confiáveis e fáceis de usar. Tenho interesse especial por sistemas internos, integrações com APIs, bancos de dados locais, importação/exportação de planilhas e interfaces web objetivas para uso corporativo.

Atualmente estou trabalhando em projetos com:

- React, TypeScript e Vite
- Node.js, Express e APIs REST
- SQLite e modelagem de dados
- Importação e exportação de planilhas
- Filas, cache, validação de dados e automações

## Projeto em destaque

### ConsultaSitCNPJ

Sistema web para consulta e atualização cadastral de empresas por CNPJ, com importação de planilhas, fila respeitando limite de API, cache local, histórico de alterações e exportação para Excel.
